# Release Checklist

This is a review draft. Complete these checks before making a GitHub repository public:

- Confirm the MIT copyright notice and ownership for the skill files and helper script.
- Check every file and the full Git history for credentials, personal paths, private hostnames, private project identifiers, customer data, and research-specific examples.
- Verify all API claims against the public Betalens source, documentation, and tests at the intended release revision.
- Confirm that examples run without private repositories, local databases, or user-specific files.
- Review generated files and repository metadata, including commit author details and Git remotes.
- Create a clean repository history for the public package; do not import private workspace history or migration artifacts.
- Review the final file list and repository visibility before publishing.
